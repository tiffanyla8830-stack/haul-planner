# TiffT0e Hauling Planner

A single-file Star Citizen cargo hauling planner. No install, no account, no
server — download the file and open it in a browser.

## What it does

- **Scan contracts** — drop in a screenshot and it reads the SCU, stops and
  commodities. The text lands in an editable box first, so you check it before
  anything reaches your contract.
- **Track hauls** — stops with locations and SCU, multi-trip planning, and a
  hold-usage check against your selected ship.
- **Personal hauls** — bought cargo rather than a paid job, with cost basis and
  sale value so you can see the actual profit.
- **Saved routes** — commodities, buy and sell costs per SCU, and run counts so
  you can see which routes earn.
- **Overview** — completed contracts, per-commodity profit breakdown, SCU totals
  and route economics.
- **Backup** — export and import your data as a file you own.

## Ships

12 cargo ships including the Drake Ironclad, Ironclad Assault, Hull C, Hercules
pair, Constellation Taurus and others, with cargo capacity and container limits.

## Notes

- Your data is stored in your browser, not on a server. Two people opening the
  same file keep separate data.
- Ship capacities and container sizes are real figures. Route economics use the
  buy and sell costs you enter yourself — nothing is guessed.
- The first time you scan a screenshot, it loads an OCR engine from a public CDN.
